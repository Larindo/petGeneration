# Dahlia Pet 角色工坊

适用范围：2026-10-29 起的本地 Dahlia Pet 分支。基于本工程的桌宠播放系统，新增独立工坊入口；原项目安装版不受影响。素材结构沿用 [ASSET-PIPELINE.md](ASSET-PIPELINE.md)。

本机验证结果与当前限制见 [DAHLIA-PET-VALIDATION.md](DAHLIA-PET-VALIDATION.md)。

## 使用

1. Windows 便携版解压整个目录，打开 `DahliaPet.exe`。首次进入角色工坊，不要求预装 Python。
2. 点击“新建角色”，填写角色名称、形象与风格。“性格与交流”页可填写性格、沟通习惯和自动台词，点击“保存角色设定”应用。
3. 选择“角色母版”，复制完整提示词给图片 AI。得到图片后，在“素材与桌宠”选择“角色母版”，点击“选择素材”。
4. 将处理好的角色母版上传给视频 AI，依次复制所需动作提示词。十种预设是待机、走路、挥手、开心、跳跃、坐下、打盹、惊讶、难过、拖拽。无需一次生成全部动作，只有母版也能生成静态待机桌宠。
5. 在素材列表选中动作，点击“选择素材”，确认后自动处理。也可打开素材目录，将文件按下表命名，勾选“自动处理新素材”；工坊打开期间会等待文件大小与修改时间稳定，再进行处理。
6. 素材处理成功后点击“使用此角色”，即可启动桌宠。新增动作后再点一次会重启由这个工坊启动的桌宠。由其他窗口启动的桌宠需自行退出后重开。
7. “导出角色包”生成可分享的 ZIP；其他用户可在自己的工坊“导入角色包”后直接使用。包内含外貌、性格、沟通习惯和自动台词，不含 API Key、个人聊天记录、原始素材或视频创作参数。

| 素材 | 文件名 | 播放用途 |
|---|---|---|
| 角色母版 | `portrait.png` / `.jpg` / `.webp` | 头像和静态待机兜底 |
| 待机 | `idle.mp4` | 待机循环 |
| 走路 | `walk.mp4` | 自动漫游 |
| 挥手 | `wave.mp4` | 点击反馈 |
| 开心 | `happy.mp4` | 点击反馈 |
| 跳跃 | `jump.mp4` | 随机动作 |
| 坐下 | `sit.mp4` | 坐下后起身的随机动作 |
| 打盹 | `sleep.mp4` | 打盹后醒来的随机动作 |
| 惊讶 | `surprise.mp4` | 点击反馈 |
| 难过 | `sad.mp4` | 随机动作 |
| 拖拽 | `drag.mp4` | 拖拽状态 |

视频也支持 `.mov` 和 VP9 `.webm`。同一个动作只留一个输入文件，避免误选。当前自动导入支持单张母版和视频，不支持直接导入 PNG 帧序列文件夹；生图/视频 AI 若只输出帧序列，需先合成视频。

## 固定与可修改

- 可修改：形象、画风、动作描述、时长、性格、沟通习惯、台词。每个动作保存自己的描述。
- 只读：英文画布、帧率、背景、构图、角色一致性和动作衔接规范，由代码统一生成，项目 JSON 不能替换固定模板。
- 走路规范固定为朝左，程序按移动方向镜像；已有朝右素材可以在导入页选择朝右，处理时会翻转。
- “不可修改”指应用内的编辑权限，不是对复制到外部 AI 后的文本施加控制；生成 AI 也可能不遵守要求，所以处理脚本仍做尺寸、透明通道和帧数校验。

2026-10-30 起，固定英文模板按完整条目输出，不再压缩成摘要。母版包含参考图优先级、画布与构图、中立姿势、背景与文件输出、禁止缺陷；动画另含逐帧身份一致性、稳定缩放、原地运动、接地要求、循环与一次性动作的衔接。先生成母版，再将母版上传给视频 AI。图片要求 PNG、动画要求 MP4，两者统一使用不透明的纯洋红色 `#FF00FF` 背景，不再要求生成 AI 提供透明通道，也不允许绘制棋盘格。透明成品由本地处理脚本生成。

角色身上不得使用洋红或接近洋红的颜色，否则色键也可能误删角色。背景必须均匀覆盖四角和肢体空隙，不含阴影、渐变或色彩反射；如角色配色冲突，应先调整角色设计再生成。已画入棋盘格的旧图不会因模板更新自动修复，建议重新生成纯色背景母版后导入。

## 性格与交流

在工坊选择自己的角色项目，打开“性格与交流”：

- 性格：例如“温柔、好奇、有一点俏皮；关心对方的感受，也有自己的想法”。
- 沟通习惯：例如“使用自然的中文，每次一到三句；称呼我为搭档，偶尔说咕咕，不连续追问”。可自行描述称呼、语言、回复长度、语气、口头禅与表情符号偏好。
- 自动台词：桌宠随机气泡的固定句子，以 `|` 分隔。它们不经过 AI，性格设定不会自动改写这些句子。

性格与沟通习惯各最多3000字，可留空。新项目带默认示例；旧项目缺少这两个字段时保持空值，不自动改写原性格。编辑会保存项目草稿；点击“保存角色设定”同步到已生成的角色包，下一条 AI 聊天请求读取新设定。无需重新抠图或生成动画。更改自动台词后可点击“使用此角色”重启桌宠以应用。

AI 交流仍需要启用聊天模块并配置有效的模型 API；这两个设置不负责开通模型，也不会自动发送测试消息。已经生成的回复与历史记录不回写，模型对口吻的遵循程度取决于模型本身。图像/视频生成提示词不掺入聊天设定。

开发契约：这两个角色项目字段为 `personality` / `communication_style`，归属工坊的“性格与交流”页，不新增全局配置键或设置搜索项。保存时验证，超限保留此前有效值并显示错误；旧项目在读取时补空字段，首次保存再写回。角色包的 `chat` 段携带设定，统一由 `character_chat()` 生成聊天提示词；本地素材处理和身份同步复用同一构造函数，处理素材不会丢弃设定。处理过程中禁用应用按钮，避免和安装并发写入。

## 自动处理

处理脚本由界面自动启动独立进程：本地抠图 → 清理边缘色 → 固定缩放和站位 → 走路步态片段选择 → 640×360 / 24fps 透明 VP9 WebM → 解码验证 → 生成 manifest → 安装角色包。

已有真实透明通道时保留；纯洋红背景使用色键；其他背景使用 U2Net。所有人物图像均在本机处理。无内置模型的版本首次会下载模型；下载失败会报错，可以联网后重试。可通过构建参数把模型一起打包，实现离线处理。

抠图和步态选择不保证修复所有生成缺陷。背景复杂、角色贴边、强烈变形或本身动作不连贯时，应重新生成素材。走路循环按相似姿态选择片段，不能凭空生成缺失的迈步。步幅采用保守估计，无法保证所有角色绝对无脚滑。跳跃/坐下等动作会保持同一缩放，不对每一帧单独缩放。

视频最长处理12秒，可填写截取起点/终点。文件失败后不自动无限重试，可替换素材或点击“重新处理失败项”。原始素材保存在项目中，不覆盖用户输入的原文件。

用户数据位于 `%APPDATA%\dahlia-pet`：

- `studio/projects/<id>/project.json`：用户可编辑字段和处理状态；
- `studio/projects/<id>/inbox/`：输入素材；
- `studio/projects/<id>/reports/`：逐动作校验与处理报告；
- `characters/<id>/`：可播放角色包；
- `config-slot-0.json`：当前桌宠配置，通过工程自己的加锁 API 写入。

新角色默认无大肥鱼随机配图，台词来自自己的项目。独立产品数据目录不迁移原版配置或聊天凭据。

## 开发与分发

源码环境使用 Python 3.11+：

```powershell
.\Setup-DahliaPet.ps1
.\Start-DahliaPet.ps1
```

命令行处理使用与界面相同的脚本：

```powershell
.\.venv\Scripts\python.exe scripts/process_character.py --project "<项目目录>" --characters "<用户角色目录>"
```

构建独立 Windows 便携版：

```powershell
.\.venv\Scripts\python.exe scripts/build_dahlia.py --model "<本机u2net.onnx路径>"
```

产物为 `dist-dahlia/DahliaPet/DahliaPet.exe` 和 `dist-dahlia/DahliaPet-Windows.zip`。分发 ZIP 或整个目录，不能只复制 EXE。构建不打包现有 shenshen 或个人 gugugaga 素材。保留原工程 LICENSE 和第三方声明；分发角色素材前由作者确认其来源与使用权限。

代码入口：`pet/character_studio/prompts.py`（固定提示词和十动作）、`project.py`（项目与角色包）、`processing.py`（固定处理脚本）、`dialog.py`（界面）、`app.py`（独立入口）。本版本增加角色创作工作流，原播放器的部分菜单与可选模块仍沿用上游名称，并非所有原版功能都已重新设计。
