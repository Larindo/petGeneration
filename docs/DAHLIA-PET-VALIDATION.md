## 处理性能

以下为单次本机测量，包含模型初始化和编码，不能当作所有设备的速度保证：

| 输入 | 输出 | 耗时 |
|---|---|---|
| 73帧走路视频，960×960 | 22帧循环，640×360，24fps，透明VP9 | 93.188秒 |
| 73帧挥手视频，960×960 | 73帧，640×360，24fps，透明VP9 | 50.547秒 |
| 已透明角色母版 | 48帧静态待机 | 1.312秒 |
| 冻结版：原视频首帧，需模型抠图 | 48帧透明待机 | 5.297秒 |
| 最终便携版复测：同一首帧，与启动检查并行 | 48帧透明待机 | 48.593秒 |

处理进程在任务结束后退出，模型不驻留桌宠播放进程。工坊自动导入开启时每2秒查看目录大小/修改时间；只有稳定且有变化时才计算文件哈希并派生处理进程。未测量完整产品内存高水位。
